# Power BI Report

## Purpose

This folder will contain the Power BI report file and supporting report documentation for the Employee Transportation Analytics project.

## Planned Report Pages

1. Revenue and Collections
2. Transportation Operations
3. Driver Payments
4. Operational Exceptions

The initial financial measures have been created in Power BI. The report pages, visualisations, and remaining analytical measures are still under development.

## Publication Checklist

Before publishing the report:

- Verify that the report uses approved synthetic sample data.
- Replace local file paths with a reproducible source configuration.
- Check that the report contains no confidential information.
- Validate relationships, measures, and financial calculations.
- Capture report screenshots after the pages are developed.
